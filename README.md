## 📖 About

🔹 **Factorio — Fluid Must Flow** is a powerful tool built to help you transport massive quantities of fluids across your Factorio factory with new high-volume pipe infrastructure. New 4x and 2x wide pipes carry dramatically more fluid than vanilla pipes, enabling late-game megabase fluid systems.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Fluid Must Flow** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Factorio modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Large Bore Pipes | New 2x and 4x size pipes with proportionally higher throughput |
| High-Volume Pumps | Industrial-scale pumps matched to large pipe capacity |
| Aesthetic Variety | Pipes available in multiple materials for visual differentiation |
| Late-Game Scaling | Designed for megabase-scale fluid systems where vanilla pipes bottleneck |
